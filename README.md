# skills-cpp

Набор скиллов для DeepSeek Harness (DSH) под C++/Qt-проект. Репозиторий — источник
правды; в профиле `~/.dsh/skills` лежат рабочие копии, поэтому после правок их нужно синхронизировать.

При синхронизации удалите устаревшую копию `~/.dsh/skills/leak-check`: каталог переименован в
`address-sanitizer`, иначе в профиле окажутся два каталога с одним именем скилла.

## Формат DSH

Скилл — это каталог `<имя>/SKILL.md` (плоский `<имя>.md` тоже допустим) в корне сканируемого
каталога. DSH читает YAML-frontmatter и показывает в каталоге только `name` и `description`;
тело загружается по требованию.

| Поле | Обязательно | Назначение |
|---|---|---|
| `name` | да | kebab-case, уникальное |
| `description` | да | когда скилл применять; это единственное, что видит модель до загрузки |
| `whenToUse` | нет | дополнительная подсказка для каталога |
| `metadata` | нет | произвольные метаданные (лицензия, источник, pack) |
| `disable-model-invocation` | нет | `true` — не показывать модели, но оставить файл ресурсом |
| `user-invocable` | нет | `false` — убрать из пользовательских команд |

Важно: вложенные `references/**/SKILL.md` DSH **не** находит как отдельные скиллы — это ресурсы
родительского скилла, которые тот читает по относительному пути. Поэтому у них стоит
`disable-model-invocation: true`, если они когда-нибудь попадут в корень сканирования.

## Приоритет правил

При конфликте выигрывает то, что выше:

1. Прямое указание пользователя в запросе.
2. Правила проекта: `AGENTS.md` → `SKILLS.md` и `cpp-codestyle`.
3. Локальные рецепты проверки: `build-and-verify`, `client-e2e-check`, `leak-check-crt`.
4. Специализированные скиллы: `core-cpp`, `architecture`, `code-review`.
5. Общий метод: `codestyle`.
6. Доменные справочники: `gRPC`, `sql-postgresql`, `ci-cd-best-practices`, `docker`, `ui-ux-design`.

Правила проекта намеренно расходятся с универсальными гайдами: здесь **запрещены** namespace,
исключения и сущности на уровне файла, а переменные — `snake_case`. Универсальные скиллы
(`core-cpp`, `codestyle`, `code-review`) содержат явную оговорку, что правила проекта и запреты
важнее их рекомендаций. Это не противоречие, а зафиксированный приоритет.

## Каталог

### Основной C++-контур

| Скилл | Когда | Роль |
|---|---|---|
| `cpp-codestyle` | любой файл `.cpp/.h/.hpp`, ревью | обязательный кодстайл воркспейса: именование, формат, запреты |
| `codestyle` | любая задача с кодом | метод «наименьшее полное изменение», YAGNI, lean diff |
| `core-cpp` | код-level C++ | C++ Core Guidelines, стандарт, темы от типов до конкурентности |
| `architecture` | системный дизайн | роутер: варианты, tradeoffs, границы, runtime/deployment, риски, ADR, паттерны |
| `code-review` | ревью PR/ветки/коммита | процесс и формат отчёта; языковые чек-листы — в `references/` |

`architecture` — только уровень системы; для одной функции или класса он не нужен. `core-cpp` —
только код; системные решения начинаются с `architecture`.

### Память и санитайзеры

| Скилл | Когда | Роль |
|---|---|---|
| `address-sanitizer` | fuzzing, порча памяти, Linux/Clang | ASan/LSan; на Windows-Qt не заменяет `leak-check-crt` |

### Доменные справочники

| Скилл | Когда | Роль |
|---|---|---|
| `gRPC` (skill `grpc-expert`) | `.proto`, стриминг, каналы | не менять уже работающий транспорт без просьбы |
| `sql-postgresql` | SQL, индексы, планы | существующая схема важнее стиля |
| `ci-cd-best-practices` | пайплайны, деплой, IaC | не применять таблицу именования к C++-коду |
| `docker` | контейнеры | только если проект реально контейнеризуется |
| `ui-ux-design` | веб-интерфейсы | не для Qt Widgets/QML — там `code-review` с `qt-review` |

## Проверка после правок

```powershell
# Windows PowerShell 5.1 (политика выполнения может блокировать .ps1)
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/validate-skills.ps1

# PowerShell 7+
pwsh -File scripts/validate-skills.ps1
```

Скрипт проверяет каждый `SKILL.md`: frontmatter парсится, `name` в kebab-case и уникален,
`description` непустой, относительные ссылки на файлы существуют. Код возврата `1` — есть ошибки.
